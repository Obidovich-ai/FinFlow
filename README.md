# 🚀 FinFlow Pro - Aqlli Moliya Tizimi

**FinFlow** — bu bizneslar uchun AI yordamida moliya tahlili, prognozlash va to'lovlarni boshqarish platformasi.

### ✨ Asosiy funksiyalar:
*   **AI Analytics:** Xarajatlar tahlili va kelajakdagi savdo prognozi.
*   **Business Dashboard:** Foyda va zararni real vaqtda kuzatish.
*   **Multi-Payment:** Click, Payme va Visa integratsiyasi.
*   **Fraud Detection:** Shubhali tranzaksiyalarni avtomatik to'xtatish.

### 🛠 Texnologiyalar:
*   **Backend:** FastAPI (Python)
*   **Database:** PostgreSQL + Redis
*   **Mobile:** Flutter (Android/iOS)
*   **DevOps:** Docker & GitHub Actions
